# Créditos y naturaleza de las visualizaciones / Visual attribution

- `yungay_aster.jpg`, `pajonales_aster.jpg`, `llullaillaco_aster.jpg`, `llaima_cone_aster.jpg`, `llaima_flows_aster.jpg` — visualizaciones sombreadas derivadas de ASTER GDEM V003 de NASA/USGS, 4 teselas originales del equipo. **No son fotografías ni imágenes ópticas en color natural**; contraste y color modificados solo para explicar la forma del relieve. Los recortes alrededor de las coordenadas de referencia no equivalen a los polígonos científicos de estudio.
- `mars_elysium_mola.jpg` — representación visual del relieve MOLA MEGDR suministrado por BJOR, para la región piloto de Elysium Planitia. No es fotografía del planeta.
- `moon_tranquillitatis_sldem.jpg` — representación visual del relieve SLDEM2015 (LOLA + Kaguya) suministrado por BJOR, Mare Tranquillitatis. No es fotografía lunar.
- `chile_outline.geojson` — referencia visual reparada y simplificada de `Regional.shp` de BCN, proporcionado por Pancho. Incluye solo la zona de longitud -76.5 a -65.5 y latitud -56.1 a -17; excluye territorios insulares fuera de ella. El original contiene geometrías inválidas; se simplificaron, corrigieron y disolvieron para **uso cartográfico visual exclusivo**. No usar para cálculos científicos, límites legales ni selección de celdas.

La visualización no implica aval ni afiliación con NASA. Derechos y condiciones de uso se rigen por las fuentes de datos originales. El inventario de datos del proyecto documenta las fuentes y limitaciones.
